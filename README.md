# 🏀 NBA Payroll Analytics

An end-to-end data science and Python development project that analyzes NBA team payrolls, player contracts, and team performance.

This project automatically collects NBA statistics and payroll data, stores them in a database, performs data analysis, and provides an interactive dashboard for exploring relationships between team payroll and on-court success.

---

## 🎯 Project Goals

This project aims to answer questions such as:

- Which NBA team has the highest payroll?
- Does spending more money lead to more wins?
- Which teams achieve the best cost performance?
- How does the Oklahoma City Thunder compare with other teams?
- How do roster changes and player transfers affect team payroll?

Ultimately, this project will become an automatically updated NBA analytics platform.
